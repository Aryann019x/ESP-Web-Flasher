# ESP32-S3 with ST7789 Display & Touchscreen Wiring Guide

This board uses an ESP32-S3 with dual-core processing, native USB, and an ST7789 panel with an XPT2046 touch controller.

## Flash the right image first

This board uses an **ST7789** panel. Use the **ESP32-S3 + ST7789 2.8"** card for your firmware group (Bruce, Marauder, or Flipper).

The standard build needs an 8MB module. Use the 16MB card only on 16MB modules, and the lite card on 4MB modules. The lite build is a reduced image that fits the 4MB partition layout; PSRAM is optional and none of these images require it.

Do not use the ILI9341 build on an ST7789 panel. The screen may still light up, but the touch calibration and orientation are different, so taps will miss or do nothing. If you already flashed the ILI9341 build, flash the ST7789 build again at `0x0000` with Erase.

Display CS (GPIO10) and touch CS (GPIO3) are separate. Sharing MOSI/MISO/SCK is normal and does not stop the touchscreen from working.

## Components

- **MCU**: ESP32-S3 (dual-core, native USB)
- **Display**: ST7789 2.8" SPI TFT LCD, 240x320, BGR colour order
- **Touchscreen**: XPT2046 resistive touch controller
- **Radio Options**: CC1101 or NRF24 on the shared SPI bus (separate CS lines)
- **I/O**: IR transmit/receive, RF transmit/receive (IR-based and 433/868MHz RF)
- **Button**: boot button on GPIO0 (active-LOW, used as OK)
- **LED / IR**: IR TX and status LED on GPIO2, IR RX on GPIO1
- **USB**: native USB (CDC + HID)
- **Storage**: microSD on the shared SPI bus (optional)

## Display Pinout (ST7789 on HSPI)

| Display Pin | ESP32-S3 Pin | Purpose |
|---|---|---|
| VCC | 3.3V | Power |
| GND | GND | Ground |
| CS | 10 | Chip Select |
| RESET | 5 | Reset (active-LOW) |
| DC | 7 | Data/Command |
| MOSI | 11 | Serial Data In |
| MISO | 13 | Serial Data Out |
| SCK | 12 | Clock |
| BL/LED | 38 | Backlight (PWM) |

## Touchscreen Pinout (XPT2046 on HSPI)

The touch controller shares MOSI/MISO/SCK with the display and has its own CS.

| Touch Pin | ESP32-S3 Pin | Purpose |
|---|---|---|
| VCC | 3.3V | Power |
| GND | GND | Ground |
| MOSI | 11 | Serial Data In (shared) |
| MISO | 13 | Serial Data Out (shared) |
| SCK | 12 | Clock (shared) |
| CS | 3 | Chip Select (touch only) |
| IRQ | Not used | Interrupt is disabled (`-1`) |

## Radio Modules (CC1101 / NRF24) - Shared SPI Bus

Both radios use the same MOSI/MISO/SCK lines as the display, touch and SD card. Each module has its own chip select, so a CC1101 and an NRF24 can be connected at the same time.

### CC1101 (sub-GHz)
| CC1101 Pin | ESP32-S3 Pin | Purpose |
|---|---|---|
| VCC | 3.3V | Power |
| GND | GND | Ground |
| MOSI | 11 | Serial Data In (shared) |
| MISO | 13 | Serial Data Out (shared) |
| SCK | 12 | Clock (shared) |
| CS | 15 | Chip Select |
| GDO0 | 6 | Data Output / RX input |

### NRF24 (2.4GHz)
| NRF24 Pin | ESP32-S3 Pin | Purpose |
|---|---|---|
| VCC | 3.3V | Power (add 10uF decoupling) |
| GND | GND | Ground |
| MOSI | 11 | Serial Data In (shared) |
| MISO | 13 | Serial Data Out (shared) |
| SCK | 12 | Clock (shared) |
| CS | 14 | Chip Select |
| CE | 16 | Chip Enable |

### W5500 (Ethernet, optional)
W5500 support is disabled in these builds (`CS=-1`). If you add one, assign free pins in the firmware settings and keep them off the display/touch CS lines.

**Note**: the CC1101 CS is GPIO15 and GDO0 is GPIO6 on this board. GPIO10 is the display CS and is not shared with the radio.

## IR & RF Pins (Single-Pin Modules)

| Function | Default GPIO | Optional GPIO |
|---|---|---|
| IR TX | 2 | 1, 8 (Grove Y) |
| IR RX | 1 | 2, 9 (Grove W) |
| RF TX (433/868MHz) | 8 (Grove Y) | 1, 2 |
| RF RX (433/868MHz) | 9 (Grove W) | 1, 2 |

> The IR defaults (TX=2, RX=1) match the IR header on this board. Pins 8/9 remain selectable for users who deliberately wired the Grove connector.

## User Input & LED

| Input/Output | ESP32-S3 Pin | Type |
|---|---|---|
| Boot Button | 0 | Tactile switch, active-LOW (used as OK) |
| IR TX / status LED | 2 | Output, active-HIGH |
| IR RX | 1 | Input |

## I2C Interface (Grove/Standard Sensors)

| Pin Name | ESP32-S3 Pin | Purpose |
|---|---|---|
| SDA | 8 | I2C Data (optional alternate IR/RF TX) |
| SCL | 9 | I2C Clock (optional alternate IR/RF RX) |

**Note**: the default IR pins are GPIO2 (TX) and GPIO1 (RX). The Grove pins are only used for IR/RF if you select them explicitly in the pin settings.

## SD Card (optional)

| SD Card Pin | ESP32-S3 Pin | Purpose |
|---|---|---|
| CS | 4 | Chip Select (SD only) |
| MOSI | 11 | Serial Data In (shared) |
| MISO | 13 | Serial Data Out (shared) |
| SCK | 12 | Clock (shared) |

## Serial Interfaces

| Interface | TX Pin | RX Pin | Purpose |
|---|---|---|---|
| USB CDC | - | - | Native USB serial (programming and debug) |
| GPS / external serial | 43 | 44 | Optional external serial module |

USB is native on the ESP32-S3 via GPIO19/GPIO20 (internal).

## Power Supply

- **Logic voltage**: 3.3V. The ESP32-S3 module is not a 5V part.
- **Current budget for this build**: ~400mA typical and ~800mA peak with radio and backlight. These are board-level estimates, not datasheet maximums.
- **NRF24 current**: the nRF24L01+ draws 11.3mA in TX at 0dBm and 12.3mA in RX (Nordic datasheet). PA/LNA modules add amplifier current; check that module's spec. A 3A supply is not required.

Use a high-quality 5V USB source rated for at least 1A, or a regulated 3.3V supply on 3V3. Fit a 10uF capacitor across the NRF24 VCC/GND.

## SPI Architecture

```
ESP32-S3 HSPI (one shared bus)
├─ ST7789 display (CS=10)
├─ XPT2046 touch (CS=3)
├─ microSD (CS=4)
├─ CC1101 (CS=15, GDO0=6)
├─ NRF24 (CS=14, CE=16)
└─ W5500 (disabled by default)

Shared: MOSI=11, MISO=13, SCK=12
```

The display, touch, SD card and radios share the same SPI bus. Each device has its own chip select, so do not tie any CS line low.

## Wiring Notes

1. **Shared SPI bus**: display, touch, SD card and radios all use GPIO11/12/13. Separate CS lines prevent conflicts.
2. **NRF24 Power**: the nRF24L01+ is a 3.3V part. Fit a 10uF capacitor across VCC/GND and never feed 5V to a bare module.
3. **Backlight**: GPIO38 supports PWM for brightness control (0-255).
4. **Reset**: display RESET (GPIO5) is active-LOW. It is normally held HIGH through a resistor or driven by the firmware.
5. **Boot Button**: GPIO0 selects the boot mode at power-up and works as the OK button at runtime.
6. **USB Serial**: native USB, no FTDI or CP210x adapter is needed on this board.
7. **Colour Order**: the ST7789 is configured for RGB to BGR conversion.
8. **SPI Frequencies**: 40MHz write, 20MHz read, 2.5MHz touch.
9. **IR pins**: the firmware defaults to GPIO2 (TX) and GPIO1 (RX). Older saved settings may still point at GPIO8/9 or GPIO40; the firmware migrates those on boot.

## Features

- **Dual-core 240MHz processor** - more headroom for radio and display work
- **Native USB** - faster uploads, serial over USB, no USB-serial chip
- **More GPIO** - enough for a display, touch, SD card and radio at once
- **Flash options** - 8MB standard, 16MB for larger modules, 4MB lite
- **IR LED driver** - GPIO2 for IR output, GPIO1 for IR input
- **Radio options** - CC1101 and NRF24 together, optional W5500 Ethernet
